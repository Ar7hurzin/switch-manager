ESCOPO DE CONFIGURAÇÃO
O que o Manager cobre
Switch não identificado

            
A configuração é organizada por tarefas. Cada operação gera uma prévia e aguarda um clique em Aplicar. O backup fica disponível como opção recomendada. O catálogo será ampliado por recurso após validar a sintaxe do VRP 3.10(CN) RELEASE 0002.

            

              
● Disponível na interfaceVLANs, access/trunk/hybrid, descrição/estado das portas, nome do switch, IP de gestão, rotas estáticas, backup e salvar.

              
◷ Pendente de validaçãoAgregação de links, STP/MSTP, espelhamento, IGMP/Voice VLAN, DHCP relay, ACL/QoS, AAA/SSH, SNMP, NTP e syslog.

              
! Depende do modelo/firmwareRecursos EI, roteamento dinâmico avançado, capacidade total de VLANs, PoE e comandos de manutenção podem variar. IDs de VLAN aceitos: 1–4094; quantidade máxima é limite de capacidade.

            

            
“Todos os comandos” varia conforme modelo, placa e firmware. Esta interface não executa texto CLI arbitrário: os recursos ainda não validados ficam identificados aqui em vez de arriscar uma configuração incorreta.

    Terminal direto: cada linha enviada é executada imediatamente no switch, sem prévia ou desfazer automático. Esta aba só conecta quando o acesso CLI for habilitado explicitamente por QM_ENABLE_CLI=true; pode alterar o equipamento mesmo quando a área guiada está bloqueada. Use um comando por vez, mantenha o cabo console conectado e revise a saída antes de continuar. A saída pode conter senhas ou hashes; ela fica visível nesta aba até você limpar a tela ou encerrá-la.
